# Интерпретатор арифметических выражений

Учебный проект на Java 21: полный конвейер обработки математических выражений —
от лексического разбора строки до символьного дифференцирования.

Выражение проходит путь:

```text
строка → Lexer → токены → Parser → дерево Expression → evaluate / simplify / print / differentiate
```

---

## Возможности

### Базовый уровень

- **Лексический анализ**: целые и дробные числа, идентификаторы, операторы
  `+ - * / ^`, скобки, запятые; пробельные символы пропускаются.
- **Синтаксический анализ**: рекурсивный спуск с приоритетами и ассоциативностью
  операций, поддержка скобок и унарных `+` / `-`.
- **Вычисление** в неизменяемом контексте переменных.
- **Встроенные функции**: `min(a, b)`, `max(a, b)`, `abs(a)`.
- **Три собственных исключения** с человекочитаемой диагностикой:
  синтаксическая ошибка (с позицией и кареткой), неизвестная переменная,
  деление на ноль.
- **Консольная демонстрация** из 12 секций + интерактивный режим.

### Повышенный уровень

- **Упрощение**: свёртка констант, нейтральные и поглощающие элементы,
  ассоциативная группировка констант, вычисление функций над константами.
- **Печать дерева в строку** с минимально необходимым числом скобок
  (round-trip: повторный разбор напечатанной строки даёт то же дерево).
- **Символьное дифференцирование** по переменной с автоматическим
  упрощением результата.

## Требования

- JDK **21+** (используются `sealed`-интерфейсы, `record`,
  switch с сопоставлением с образцом, перечисления с телами констант);
- Maven 3.6+;
- сторонних библиотек нет (JUnit 5 — только в test-scope).

## Структура проекта

```text
src/main/java/org/example/
├── cli/            Main, Demo — точка входа и консольная демонстрация
├── exception/      SyntaxException, UnknownVariableException, DivisionByZeroException
├── expression/     Expression (sealed) + Number, Variable, Unary, Binary, FunctionCall
├── lexer/          Lexer, Token, TokenType
├── operation/      BinaryOperation, UnaryOperation, FunctionOperation, Associativity
├── parser/         Parser — рекурсивный спуск
├── service/        EvaluationContext — неизменяемый контекст переменных
└── transform/      Simplifier, PrettyPrinter, Differentiator

src/test/java/      JUnit 5 тесты всех уровней
```

Модель выражений — закрытая иерархия: `sealed interface Expression`
с пятью реализациями-записями. Все узлы неизменяемы; изменяемые коллекции
защищённо копируются (`List.copyOf`, `Map.copyOf`).

## Грамматика и приоритеты

```text
expression      → additive
additive        → multiplicative (('+' | '-') multiplicative)*
multiplicative  → unary (('*' | '/') unary)*
unary           → ('+' | '-') unary | power
power           → primary ('^' unary)?
primary         → NUMBER | IDENTIFIER | functionCall | '(' expression ')'
functionCall    → IDENTIFIER '(' arguments ')'
```

| Операция        | Приоритет | Ассоциативность |
|-----------------|-----------|-----------------|
| `+`, `-`        | 1         | левая           |
| `*`, `/`        | 2         | левая           |
| унарные `+`, `-`| между 2 и 3 | —             |
| `^`             | 3         | **правая**      |

Принятые соглашения:

- `-2 ^ 2` интерпретируется как `-(2 ^ 2) = -4`, а не `(-2) ^ 2 = 4`;
- `2 ^ 3 ^ 2 = 2 ^ (3 ^ 2) = 512` (правая ассоциативность);
- `10 - 2 - 3 = (10 - 2) - 3 = 5` (левая ассоциативность).

## Сборка и запуск

```bash
mvn compile
java -cp target/classes org.example.cli.Main                 # автодемо + интерактив
java -cp target/classes org.example.cli.Main --interactive   # только интерактив
mvn test                                                     # прогон тестов
```

Автодемонстрация последовательно показывает: наполнение модели объектами
(≥ 30 узлов), разбор, вычисление, переменные, функции, скобки, унарный минус,
степень, обработку ошибок, упрощение, печать и дифференцирование.

Пример вывода:

```text
=== 6. Скобки меняют приоритет ===
2 + 3 * 4              = 14
(2 + 3) * 4            = 20
10 - 2 - 3             = 5
10 - (2 - 3)           = 11
```

## Интерактивный режим

| Ввод                    | Действие                                    |
|-------------------------|---------------------------------------------|
| `<выражение>`           | разобрать и вычислить в текущем контексте   |
| `/simplify <выражение>` | упростить выражение                         |
| `/print <выражение>`    | напечатать с минимальными скобками          |
| `/diff <выражение> by x`| взять производную по переменной             |
| пустая строка / `exit`  | выход                                       |

Пример сессии (контекст: `x = 4`, `y = -2`, `z = 0.5`):

```text
> 2 + 3 * 4
  2 + 3 * 4  =  14
> /simplify 2 * 3 + x * 1
  2 * 3 + x * 1  →  6 + x
> /diff x^2 + 3*x by x
  d/dx(x^2 + 3*x) = 2 * x + 3
> 2 + * 3
  2 + * 3
      ^
  Syntax error in position 5: Expect digit, variable, function or '('
```

## Обработка ошибок

| Исключение                | Этап        | Пример входа     |
|---------------------------|-------------|------------------|
| `SyntaxException`         | разбор      | `2 + * 3`, `(1 + 2` |
| `UnknownVariableException`| вычисление  | `q + 1`          |
| `DivisionByZeroException` | вычисление  | `1 / 0`, `x / (y - y)` |

`SyntaxException` хранит позицию ошибки (внутренняя нумерация с нуля,
в сообщении — с единицы) и исходную строку; сообщение содержит строку
с кареткой под проблемным символом.

## Повышенный уровень: детали

### Упрощение (`Simplifier`)

| Правило                                            | Результат |
|----------------------------------------------------|-----------|
| `a op b`, оба числа (кроме деления на 0)           | число     |
| `x + 0`, `0 + x`, `x - 0`, `x * 1`, `1 * x`, `x / 1`, `x ^ 1` | `x` |
| `x * 0`, `0 * x`, `0 / x` (x ≠ 0)                  | `0`       |
| `x ^ 0`                                            | `1`       |
| `+x`, `-(-x)`                                       | `x`       |
| `-(число)`                                          | число     |
| `a * (b * x)`, `a + (b + x)`, `a - (b + x)` (a, b — числа) | группировка констант |
| `min/max/abs` над числами                           | число     |

Деление на ноль намеренно **не** сворачивается: ошибка должна возникнуть
на этапе вычисления как `DivisionByZeroException`.

### Печать (`PrettyPrinter`)

Скобки ставятся только там, где без них изменится структура дерева при
повторном разборе: по приоритетам, ассоциативности и стороне ребёнка.
Гарантируется round-trip `parse(print(t)) == t` для деревьев, порождённых
парсером.

```text
2 + (3 * 4)  →  2 + 3 * 4        (a - b) - c  →  a - b - c
(2 + 3) * 4  →  (2 + 3) * 4      2 ^ (3 ^ 2)  →  2 ^ 3 ^ 2
-(2 ^ 2)     →  -2 ^ 2           (-2) ^ 2     →  (-2) ^ 2
```

### Дифференцирование (`Differentiator`)

| Выражение | Производная по `x`            |
|-----------|-------------------------------|
| `c`       | `0`                           |
| `x` / `y` | `1` / `0`                     |
| `a ± b`   | `a' ± b'`                     |
| `-a`      | `-a'`                         |
| `a * b`   | `a'·b + a·b'`                 |
| `a / b`   | `(a'·b − a·b') / b²`          |
| `a ^ n`   | `n·a^(n−1)·a'` (n — константа)|

Результат автоматически упрощается: `d/dx(3 * x^2) = 6 * x`.

## Ограничения

- Дифференцирование `min`, `max`, `abs` и степени с **переменным** показателем
  не поддерживается (`UnsupportedOperationException`).
- Числа представлены как `double`; научная нотация при печати переводится
  в обычную десятичную запись.
- Отрицательные числовые литералы появляются только после свёртки констант
  (парсер представляет `-5` как `Unary(NEGATIVE, Number(5))`), поэтому
  структурный round-trip печати гарантирован для деревьев, порождённых
  парсером; для упрощённых деревьев гарантируется совпадение значений.
- Принято соглашение `0 ^ 0 = 1`.

## Тесты

`mvn test` прогоняет JUnit 5 тесты, покрывающие:

- лексер: токены, позиции, лексические ошибки;
- парсер: приоритеты, ассоциативность, унарные операции, скобки, функции,
  синтаксические ошибки;
- вычисление: базовые случаи, переменные, функции, деление на ноль;
- контекст: неизменяемость, неизвестная переменная;
- упрощение: каждое правило отдельно и ассоциативная группировка;
- печать: round-trip и минимальность скобок;
- дифференцирование: каждое правило и комбинации.
